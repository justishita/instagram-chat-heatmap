# Instagram Conversation Visualizer

An interactive web application that parses Instagram data exports and visualizes conversation activity using GitHub/Leetcode-style heatmaps, streak analysis, engagement statistics, and user comparison dashboards.

## Overview
This project transforms Instagram message exports into an interactive analytics dashboard where users can explore conversation activity, track engagement trends, compare interactions, and discover long-term communication patterns through visual heatmaps.

Inspired by Leetcode's activity visualization, the application presents messaging activity in a familiar and intuitive format.

## Features

### Activity Heatmaps
- Leetcode-style activity visualization
- Daily interaction tracking
- Yearly and monthly activity views
- Interactive hover tooltips

### Conversation Analytics
- Total interaction count
- Active days tracking
- Longest conversation streak
- Most active conversation dates

### Interaction Type Filtering
Analyze activity separately for:
- Messages
- Photos
- Videos
- Audio Messages
- Combined Activity

### User Comparison Dashboard
- Compare two conversations side-by-side
- Visualize activity differences
- Compare engagement levels and streaks
- Analyze interaction patterns across users

### Conversation Explorer
- Browse all conversations
- Search users instantly
- View individual conversation statistics
- Explore historical interaction trends

## How It Works

1. Request your Instagram data export.
2. Download the export in JSON format.
3. Upload the ZIP file into the application.
4. The application parses message history locally.
5. Conversation data is aggregated by date and interaction type.
6. Activity is visualized through interactive heatmaps and analytics dashboards.

## Getting Instagram Data

1. Open Instagram
2. Go to Settings
3. Navigate to **Your Activity**
4. Select **Download Your Information**
5. Choose:
   - JSON Format
   - Messages
6. Download the generated ZIP file
7. Upload it into the application
